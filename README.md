#  📚 Topics Covered:

---

## 1. Statistics 📊:

Statistics is the mathematical foundation of data science. It provides the frameworks and tools required to transform 
raw, noisy data into verifiable insights—preventing algorithms from becoming unguided "black boxes."

### ✅ Topics Covered:

- Measures of Central Tendency.
- Measures of Variability.
- Percentiles & Quantiles.
- Skewness.

---

## 2. Probability 🎲:
Probability provides the mathematical framework for working with uncertainty, randomness, and incomplete 
information—enabling data science models to make probabilistic predictions rather than deterministic guesses.

#### ✅ Topics Covered:

- Random Variable.
- Probability.
- Probability Distribution.

---

## 3. Covariance & Correlation 📈:

Covariance and correlation both measure how two continuous variables move together, 
but correlation standardizes covariance into a scale-independent metric ranging from −1 to +1.

### ✅ Topics Covered:

- Covariance.
- Correlation.
- Central Limit Theorem.

---

## 4. Hypothesis Testing 🧪:

Hypothesis testing is a formal statistical framework used to determine whether an observed effect 
or difference in sample data is statistically significant or merely a result of random chance.

### ✅ Topics Covered:

- Hypothesis Testing
- Z-Test
- T-Test
- Chi-Square-Test

---

## 5. Data Cleaning & Preprocessing

Data cleaning and preparation is the essential first step in data science that fixes raw, messy data. 
It involves removing duplicates, handling missing values, correcting structural errors, and filtering 
outliers to make datasets accurate and ready for machine learning

### ✅ Topics Covered:

- Variables in Dataset.
- Data Cleaning.
- One-Hot Encoding.
- Label Encoding.
- Ordinal Encoding.

---

## 6. Machine Learning 🤖:

Machine learning (ML) provides the predictive algorithms and automation tools that data scientists 
use to extract actionable insights from large datasets.

### ✅ Topics Covered:

- Machine Learning
- Variables in Machine Learning
